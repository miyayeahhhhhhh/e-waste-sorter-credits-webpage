About Project

Smart IoT-Powered
E-Waste Management

EcoBin is a final-year engineering project that bridges hardware and software to tackle the growing e-waste crisis. Our Arduino-based smart bin identifies and weighs disposed electronics, then rewards users with eco-credits through a real-time web platform.

Every time you drop in an old phone, charger, or battery — sensors detect it, Arduino processes the signal, and your account is credited instantly. It's recycling reimagined for the digital age.

  • Real-time Arduino ↔ Web communication
  • IoT sensor integration (weight + IR)
  • Gamified recycling with reward credits
  • Leaderboard and impact tracking
  • Redeemable eco-rewards program

How It Works

Four simple steps from waste to rewards

01
Drop E-Waste
Insert your old electronics into the EcoBin slot — phones, chargers, batteries, earphones, cables, and more.
02
Sensor Detects
Arduino's IR and weight sensors identify the item type and mass. Data is processed onboard in milliseconds.
03
Signal Sent
ESP8266 WiFi module transmits a secure HTTP POST request to our web server with item details and user PRN.
04
Earn Credits
Your account is instantly credited. Watch your eco-credits grow and redeem them for real rewards and coupons.

Arduino Code (Main Sketch)
// EcoBin Arduino Sketch - Main Controller
// Connect: IR Sensor (D2), HX711 (D3/D4), ESP8266 (RX/TX)

#include <SoftwareSerial.h>
#include "HX711.h"

#define IR_PIN     2
#define HX711_DT   3
#define HX711_SCK  4
#define LED_GREEN  8
#define LED_RED    9

HX711 scale;
SoftwareSerial esp8266(10, 11); // RX, TX

const char* USER_PRN = "PRN2024001";
const char* SERVER   = "192.168.1.100";

void setup() {
  Serial.begin(9600);
  esp8266.begin(115200);
  scale.begin(HX711_DT, HX711_SCK);
  scale.set_scale(2280.f);
  scale.tare();
  pinMode(IR_PIN, INPUT);
  pinMode(LED_GREEN, OUTPUT);
  pinMode(LED_RED, OUTPUT);
  Serial.println("EcoBin Ready...");
}

void loop() {
  if (digitalRead(IR_PIN) == LOW) {
    delay(500); // debounce
    float weight = scale.get_units(5);
    Serial.print("Weight: ");
    Serial.println(weight);
    sendToServer(weight);
    delay(3000);
  }
}

void sendToServer(float weight) {
  String payload = "prn=" + String(USER_PRN) +
                   "&weight=" + String(weight);
  esp8266.println("AT+CIPSTART=\"TCP\",\"" + 
                   String(SERVER) + "\",80");
  delay(1000);
  String req = "POST /api/recycle HTTP/1.1\r\n" +
               "Host: " + String(SERVER) + "\r\n" +
               "Content-Length: " + payload.length() + "\r\n\r\n" +
               payload;
  esp8266.println("AT+CIPSEND=" + String(req.length()));
  delay(500);
  esp8266.print(req);
  digitalWrite(LED_GREEN, HIGH);
  delay(2000);
  digitalWrite(LED_GREEN, LOW);
}
Example API Endpoint (Node.js / Express)
// EcoBin API Server — /api/recycle endpoint
const express = require('express');
const app = express();
app.use(express.urlencoded({ extended: true }));

const wasteTypes = [
  'Battery', 'Mobile Phone', 'Charger',
  'Earphones', 'Laptop Parts', 'USB Cable'
];

// Calculate credits based on item weight
function calcCredits(weight) {
  if (weight < 50)  return 5;
  if (weight < 200) return 10;
  if (weight < 500) return 20;
  return 30;
}

app.post('/api/recycle', (req, res) => {
  const { prn, weight } = req.body;
  const user = db.findByPRN(prn);
  if (!user) return res.status(404).json({ error: 'User not found' });
  
  const credits = calcCredits(parseFloat(weight));
  const wasteType = wasteTypes[Math.floor(Math.random() * wasteTypes.length)];
  
  user.credits += credits;
  db.addHistory(prn, { wasteType, credits, weight, timestamp: new Date() });
  
  res.json({ success: true, credits, total: user.credits, wasteType });
  broadcastUpdate(prn, credits); // WebSocket push to dashboard
});

app.listen(3000, () => console.log('EcoBin API running on port 3000'));
